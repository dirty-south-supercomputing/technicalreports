It is possible for more than one IV+level configuration to be optimal for a given Pokémon in a given League. The optimal Master League configuration is always the “maxed out” 15-15-15 IVs at Level 50. These Pokémon each have a configuration functionally equivalent to that configuration. Pokémon incapable of meeting the Ultra League CP bound of 2500 are not included.
